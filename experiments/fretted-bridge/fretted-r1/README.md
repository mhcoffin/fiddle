# Fretted instruments r1

[Importable map](Fiddle-Fretted-r1.doricolib), generated
[allocation](allocation.md) and full [built-in disposition](inventory.md).
Scope, vocabulary and open questions: [the section README](../README.md).

Wire schema 2 (typed Offs, revision beacon on KS126/127), with Dorico's
note-duration playback options pinned to 100% from the first revision, as
in strings r5 and pitched percussion r2: Dorico sends written lengths, and
Fiddle applies the duration percentages per layer. Dynamics use the pinned
linear curve over −8..8 with no articulation deltas.

Not yet host-verified. Regenerate from the repository root with
`python3 experiments/fretted-bridge/generate_fretted.py` (add `--check` to verify).
