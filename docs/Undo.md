# The Fiddle Server should support undo/redo of the following operations:

* Adding an instrument to the setup
* Removing an instrument from the setup
* Adding a strip to the project
* Deleting a strip from the project
* Changing the library of an instrument
* Changing the expression map for an instrument
* Changing the VST for an instrument
* Changing the gain on a strip
* setStripInput
* duplicateStripInput
